# 门 A 的 `autoImplicit` 洞 —— 全量体检（只统计，未改判据）

2026-11-08 02:24 CST ｜ 服务器 `211.159.188.206` ｜ Lean 4.31.0 + `deploy/mathlib-olean`

## 为什么查这个

命题级探针（`测试结果/命题级探针_20261107/`）发现：模型写

```lean
example (a : ℤ) (ha : a ≠ 2) : (∃ d : ℤ, d * d = D) ↔ ... := by sorry
```

其中 `D` **从未声明**，但 Lean 的 `autoImplicit`（默认开）把它绑成**全称量化的隐式变量**，
于是编译 `rc=0` ⇒ 判 STATABLE，而实际陈述的东西与原命题无关。

门 A 的 `contracts/formal_sig_gate.py::classify_stated()` 只吃 `(returncode, full_err)`，
真正决定口径的是 `agent/sub_goal_solver__lean.py::_compile_stated()`：
它只做 Mathlib import 归一化后原样编译，**没有关 `autoImplicit`** ⇒ 同洞。

本轮任务：把洞的影响面量出来，**不改判据**。

## 口径（单变量）

- 人群：`/tmp/sig_gate_res.json`（E31 回放，10 个 run 日期 20261015–20261030），
  151 条带 `sorry` 的形式签名；其中 7 条被零成本门（SHAPE / NONTRIVIAL）拦下，
  **144 条进入门 A 编译**。
- 每条编译两次，唯一差异是多一行：
  - A 基线：`import Mathlib.Tactic` + `set_option maxHeartbeats 400000` + 签名
  - B 处理：同上，导入后加 `set_option autoImplicit false`
- 串行（单文件 ~2.4s / 峰值 3.4GB，7.5G 内存下并发必 OOM）。90 条 × 2 次 = 394 秒。

## 人工抽验（必须，已做）

三条逐条看过原文与同题相邻子目标：

1. `spider_presence_does_not_affect_max_path_length` 是把**一句英文句名**放在命题位置，
   本身不是命题。同 run sg2 的 `90_turn_extension` 也是自造记号（那条以数字开头，
   被语法检查正确挡下）。⇒ 真拦对了。
2. `score ≤ M + 1` 里的 `M` 在整题任何签名里都没有作为参数出现，
   也没有任何定义 ⇒ 自由名，不是「我漏看了 binder」。⇒ 真拦对了。

**3/3 抽验成立，无误杀。**

## 本轮未覆盖的（不要外推到「门 A 已干净」）

`autoImplicit` 只能挡「自由名」这一种。命题级探针里另外两种
**编译能过但语义错**，这个改动一样挡不住：

- **恒假命题**：`q2a_p04` 把因式分解写成恒假等式（a=2/3/5/10 数值验算全不等）
- **空真命题**：`q2a_p05` 前件恒假，一秒可证但什么都没说

⇒ 3.3% 是**洞 1 的**影响面，不是「门 A 的总漏判率」。

## 若要修（本轮未修，等拍板）

改动点（判据语义变更，按项目规矩须用户确认 + 留出集 + 分层 + 人工抽验）：

3. 探针侧（`l2_prop_probe.py` / `l2_step_probe.py`）可选。

实现注意：`set_option` 必须落在 **import 之后**。本批 151 条签名 **0 条带 import**，
所以直接前插也安全；但签名若自带 `import Mathlib.Tactic`（历史上出现过），
前插会变成 `set_option` 先于 `import` ⇒ Lean 报错。正确做法是插在最后一行前导 import 之后。

单测影响：`tests/test_formal_sig_gate.py` 对 `classify_stated` 是纯函数测试

⇒ 预期零改动。需实跑 `pytest tests tools -q` 确认。
