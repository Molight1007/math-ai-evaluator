# 45 题评测错题详解（详细版）：错误传递链 × 全中文环节耗时

- **评测轮**：2026-09-07 晚，全开版本（子目标轻量校验/上下文注入/验证增强护栏/翻译剥壳修复），禁网模拟比赛环境
- **样本**：同一份 45 题、同模型；本文覆盖 **25 道错题**
- **时间口径**：阶段计时器记录的各环节 CPU 秒，文中统一换算为**分钟**（保留 1 位小数）；总时长=该题全程耗时
- **错误类型中文对照**：值错=最终数值与标准不符；式错=表达式/集合与标准不符；格式=答案格式未被识别（多为等价写法判分问题）；提取失败=未能从回答中抽出答案
- **状态图例**：✓=该环节正确 / ✗=该环节出错 / ◆=空转或工具失败（求解器拒绝表达式等）

## 〇、全流程环节说明（答案是怎么走完一条流水线的）

一道题从读题到出答案，依次经过以下环节。下文每道错题都按这条链路标注「答案在哪个环节、以什么状态传递」：

| 环节 | 环节职责 | 答案在这里发生什么 |
|---|---|---|
| ① 蓝图设计 | 读题后把解法拆成若干步骤节点并做可行性审查 | 决定「用什么方法、先证什么后证什么」——**这里错了后面全错** |
| ② 子目标求解 | 按蓝图逐个求解中间结论（含计算工具辅助） | 产生中间量：引理、数值、构造。此处空转/算错会带病进入下一步 |
| ③ 候选生成与补全 | 把子目标结论组织成候选答案 | 蓝图/子目标的结论在此汇总成可输出的答案文本 |
| ④ 答案验证 | 对候选做验证/对抗复核 | 应在此拦截错误，但「自洽通过」≠「与标准答案一致」 |
| ⑤ 修订打回 | 验证不过时携带反馈重做 | 打回轮数越多，说明前面环节错得越深 |
| ⑥ 终审门 | 最后一道门，决定放行或降级 | 超时/无法判定时可能跳过真正校验 |
| ⑦ 输出对比 | 从回答文本提取答案与标准比对 | 文本等价但写法不同 → 判分误杀；提取失败 → 判错 |

## 二、每题答案传递链（错误如何在各环节间传递）

> 每题一个小表：按 ①蓝图 → ②子目标 → ③合并/候选 → ④验证 → ⑥输出 的顺序列出「每一步传下去的是什么、对还是错」，最后一行是标准答案对照与诊断。

### 1. alg-003（代数·深档·18.5 分钟·式错）
| 环节 | 传递内容 | 状态 |
|---|---|---|
| ①蓝图 | 先证 g(0)=0，再证 g 是**不高于 2 次的多项式**，代入求系数 | ✗ 假设漏掉 x³+c 族 |
| ②子目标 1-3 | g(0)=0、代入 z=0、交换 x→-x → g 为奇函数 | ✓ |
| ②子目标 4-5 | 设 g=ax²+bx（继承错误假设）代入方程做系数比较 | ✗ 错误假设固化 |
| ②子目标 6 | 比较系数得 a=0, b=±2 | ✗ 结论在窄假设内"正确" |
| ②子目标 7-8 | 验证 g=±2x 满足方程（自洽） | ✓(自洽) 但对象错 |
| ③合并输出 | 蓝图合并："多项式限制为二次，系数比较得 g=±2x" → 输出 g(x)=-2x | ✗ |
| ④验证/终审 | 自洽通过（绿点），未与标准核对 | ✗ 放行 |

**诊断**：错误起源在最上游蓝图——把解族假设成二次多项式。子目标全部在错误假设下自洽推进，验证器因"自洽"放行，10.5 分钟的子目标时间全部浪费在错误方向上。

## 四、错误模式归纳与对策（按可挽救价值排序）

| 错误模式 | 涉及题目 | 共同特征 | 对应对策 |
|---|---|---|---|
| **① 蓝图假设即错** | alg-003/068/091、comb-027/040、nt-022/037/077 | 上游拆解方向/前提错误，下游全部自洽空转；绿点照常放行 | 蓝图结论与题目做轻量反向核对（答案族是否覆盖题目条件），在子目标主段前拦截 |
| **② 子目标空转/漏分支** | alg-009/060、comb-022、nt-031/057、nt-037 | [计算]0=0 占位被当成结论、关键分支漏数、自相矛盾无人核对 | 空转检测升级：0=0/1=1 结果禁止作为子目标结论；子目标间数值交叉核对 |
| **③ 计算工具断链** | comb-024、geo-068、nt-031/096、1000_0466、多元_005 | 求解器白名单拒绝符号式/根号/对数，断链后手工补救必错 | 计算工具放开符号变量（Name 节点）与常用函数，或断链时显式降级标记而非硬算 |
| **④ 蓝图审查信号被无视** | comb-032、geo-051、nt-031/037/077/096 | 审查拒绝率 40-60% 并建议重规划，实际修订轮数=0 | 建议重规划时强制进入修订循环（带反馈），这是成本最低的救回点 |
| **⑤ 判分/金标准误杀** | alg-084/087、一元_003、多元_005 | 模型答案与标准等价，判分器按文本判错；1 题金标准存的是过程 | 判分器做「等价形式归一化」（剥 $/合并同义描述）；修多元_005 金标准 |
| **⑥ 输出端漂移** | alg-053/068、comb-040、geo-068、1000_0968 | 蓝图/合并/输出三处数值互不一致，最终输出与上游结论都对不上 | 输出前与蓝图结论做一致性断言，不一致即打回 |

**一句话总结**：25 道错题里约 4 题是判分误杀（修判分即可 +4），约 7 题死在"蓝图审查已亮红灯但无人重规划"，其余多为上游空转与计算工具断链——**改进杠杆全在流水线前 40%（蓝图+子目标），验证端再强化也拦不住这些错**。
