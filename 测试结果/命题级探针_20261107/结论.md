# 命题级探针（2026-11-07）：把「逐动作翻译」换成「逐命题翻译」

## 0. 结论一句话

**可陈述 11/14（78.6%），语义忠实只有 6/14（43%）。** 而且失败的 3 条里，
**有 3 条是「编译通过但命题不是原意」**——绿勾恰好盖在最危险的地方。
这条路作为「自动判断」不成立；作为「人工抽验的辅助」还有空间。

## 1. 设计（与上一轮「逐动作翻译」的区别）

原方案（用户提出）：模型写自然语言 → 把每个**动作**翻译成 Lean → 编译判对错。
问题：动作不可验证，且译文≠原文时绿勾是假的。

本探针改成**只翻命题**：

```
模型用中文写完整证明
  → 抽取「中间结论」列表，每条强制自包含（变量类型 + 前提全部显式）
  → 每条独立翻译成 `example ... := by sorry`
  → 只验「可陈述」（rc==0，allow sorry）
```

三条硬约束：①每条自包含；②只判可陈述，不判可证（可证是另一层）；
③每条独立编译、独立定位失败，不依赖前一条是否成功。

## 3. 三条「编译通过但语义错」的样本（最重要的发现）

### 3.1 未声明符号被 autoImplicit 吞掉（`q2a6f8743_p06`）

模型写的：

```lean
example (a : ℤ) (ha : a ≠ 2) : (∃ d : ℤ, d * d = D) ↔ (∃ k : ℤ, k * k = 4 * a + 1)
```

`D` **从未声明**。Lean 的 `autoImplicit` 默认开启，把它自动绑定成全称量化的隐式变量，
于是编译 rc=0，判为 STATABLE。加一行 `set_option autoImplicit false` 后：

```
error(lean.unknownIdentifier): Unknown identifier `D`
Note: It is not possible to treat `D` as an implicitly bound variable here
      because the `autoImplicit` option is set to `false`.
```

⇒ 这条命题实际陈述的是「对**任意** D，D 是完全平方当且仅当 4a+1 是完全平方」，
与「判别式 D=4a³−15a²+12a+4 可因式分解」毫无关系，且为假。

### 3.2 恒假命题（`q2a6f8743_p04`）

NL：「D 可因式分解为 (a−2)²(4a+1)」。Lean 写成：

```lean
(a - 2)^2 * (4 * a + 1) = a^2 - 4*a + 4*(4*a + 1)
```

右边 = a²+12a+4，不是 D。数值验算 a=2/3/5/10 全不相等（0≠32、13≠49、189≠89、2624≠224）。
**编译照样通过**——因为 `:= by sorry` 不看证明，只看命题能不能 elaborate。
这种句子的危险在于：它永远证不出来，但我们如果只看「可陈述」就会收下它。

### 3.3 空真命题（`q2a6f8743_p05`）

NL：「a=2 时 D=0，但对应 b=−1 不是正整数，故排除」。Lean 写成：

```lean
∀ (b : ℕ), (0 : ℤ) = 7 * (2:ℤ)^2 + 2 * ↑b + ↑b^2 → b ≤ 0
```

前件在 `b : ℕ` 下恒假（右边 ≥28，不可能等于 0），所以整句**空真**，
证起来一秒，但什么都没说。原文里的「b = −1」这个关键信息（负解）完全消失。

## 4. 另外两类（较温和）

- **写不成合法 Lean（3 条）**：`q03_p06` 把中文的「{x,y,z} 中恰有一个」写成
  `∃! v : {x, y, z}`（把集合当类型）；`q2a_p01` 在 ℕ 上用 `^(1/3 : ℝ)` 无实例；
  `q2a_p08` 直接把命题改写成了另一件事。
- **语义漂移（2 条）**：`q2a_p02` 把「正整数 a,b」换成实数，把「可整理为」写成 `↔`；
  `q03_p01` 的「等号成立当且仅当线性相关」写成「存在单一 k 使 (a,b,c)=k(d,e,f)」，
  在 (d,e,f)=0 的退化情形不等价。

## 5. 对生产闸门的影响（重要，需拍板）

`contracts/formal_sig_gate.py` 的 `classify_stated()` 用「保留 `:= by sorry` 原样编译」
判可陈述，但**没有关闭 `autoImplicit`**。也就是说同样的洞在门 A 上存在：
一个引用了未声明符号的签名会被当成 STATABLE。

- 影响面：只看现象，不能外推数量——历史 144/144 复现的样本里尚未统计过未声明符号。
- 修法：编译前缀加 `set_option autoImplicit false`（一行）。
- **但这是判据语义变更**（会让一部分原本 STATABLE 的签名变成 ILLEGAL），
  按项目规矩须用户拍板 + 留出集 + 抽验，本轮**不改**。

## 6. 不宣称

- 不宣称可陈述率 78.6% 是效果量：n=14，单题单次采样，且与 E37 的 69% 不同源、不同 prompt，**不可比**。
- 不宣称忠实率 43% 是模型能力的估计：忠实与否由助手逐条人审，只有一评者，无第二人复核。
- 不宣称这条路完全不可行：它至少能自动挡掉「写不成 Lean」这一类（3/14），
  真正无法自动化的只有语义层。
- 不宣称原型可用：本探针只做到「抽命题 + 翻译 + 判可陈述」，**没有做逐条证明**，
  也没有做依赖排序与整体拼接。
