## 一、文件清单

| 文件 | 字段 | 用途 |
|---|---|---|
| `official112_questions.jsonl` | `id / question / domain` | **喂给被测模型**（无答案、无提示，防泄漏） |
| `official112_gold.jsonl` | `id / answer` | **判分对照**（只给评测器用） |
| `official112_full.jsonl` | `id / question / domain / answer / meta` | 一站式完整版；字段兼容常见 loader |

**推荐接法**：模型只看 `questions`，判分器拿 `gold` 按 `id` 对齐；`full` 用于一步到位的评测流水线。

## 四、快速使用

### 4.1 读取（纯标准库，无依赖）

```python
import json

def load(p):
    return [json.loads(l) for l in open(p, encoding="utf-8") if l.strip()]

questions = {r["id"]: r["question"] for r in load("official112_questions.jsonl")}
gold      = {r["id"]: r["answer"]   for r in load("official112_gold.jsonl")}

for qid, q in questions.items():
    pred = my_model(q)          # 你的模型/智能体
    print(qid, pred == gold[qid])
```

### 4.2 判分的坑（务必注意）

- **数值题**（占 55%）：先解析成数值再比较（`Fraction` 比浮点更稳），注意 `1/2` 与 `0.5`、千分位逗号、百分号、带单位等情况。
- **表达式题**：不要直接字符串比对，会大面积**假阴性**。建议先做归一化（去空格、统一 `\left\right`、`\frac` 形式）或符号等价判断（SymPy `simplify`）。
- **多值答案**（如 `2026, 2030`）：建议按分隔符拆成集合比较。
- **选项/判断题**：大小写归一后精确匹配即可。
- 模型输出通常包在 `\boxed{...}` 里，**先抽取 boxed 内容再判分**；抽取失败会显著压低分数（建议单独统计"抽取失败"比例）。

## 五、使用须知（重要）

1. **答案来源**：题面与核定答案取自公开数学评测资料包的核定表（`problem` + `ground_truth`），**逐字保留、未改写**。
2. **防泄漏**：`meta.card_titles` / `meta.card_hints` 中含解法思路与答案线索。
   - ✅ 判分阶段使用无害；
   - ❌ **不要与题面一起喂给被测模型**——会污染测试结果（等于给提示）。
   - 若不确定，模型侧一律只用 `official112_questions.jsonl`。
3. **合规**：本库用于**离线/本地评测**。如需用于线上竞赛或平台的正式提交链路，请先自行核对该赛事规则，避免与"答案回灌/提示污染"相关条款冲突。
4. **正确率含义**：题目全部带核定答案，测出的是**模型推理能力 + 答案抽取/判分口径**的混合结果；若要纯净衡量推理，建议同时报告"抽取失败率"。
5. **已知缺口**：
   - 25 题无 `domain` 标注（`idx`：15, 21, 27, 48, 50, 52, 62, 63, 64, 65, 66, 78, 86, 88, 91, 92, 93, 94, 95, 96, 98, 99, 100, 109, 110），实测均为竞赛题，可按需自行补标；
   - `meta.card_*` 关联基于"答案值相等"，个别通用答案（如 `8`、`2`）可能存在归属歧义——**不影响判分**（判分只读 `answer`）。
