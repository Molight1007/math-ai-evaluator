## 一、为什么要加这一层

现有 49 题测的是**判断**层面的严格性：
> 给模型一个被改坏的定理 → 它能识破吗 → ✅ B3 / D2 / D4 已覆盖

还有更严的一层是**陈述**：
> 让模型**自己输出**一个定理的完整条件 → 它能列出全部吗 → ❌ **当前无题**

**能判断 ≠ 能精确陈述。** 举例：

| | 判断层（已测） | 陈述层（待测） |
|---|---|---|
| 拉格朗日中值定理 | 把"开区间可导"去掉，看它能否识破 | 让它自己写出"闭区间连续 **且** 开区间可导" |
| 费马小定理 | 把素数 p 换成合数 4，看它能否找反例 | 让它写出"p 是素数 **且** p ∤ a **且** a^(p-1) ≡ 1 mod p" |
| 柯西-施瓦茨 | 在内积空间条件缺失时能否识破 | 让它说出"内积空间 + 正定性" |

陈述层是"严格理解"的最后一公里——**论文不能没有它**。

## 二、测三件相关但不同的事

| 子维度 | 核心问题 | 例子 |
|---|---|---|
| **条件完整性** | 能否列出定理的**全部条件**？ | 拉格朗日：闭区间连续 + 开区间可导 |
| **量词精确性** | 能否正确处理 ∀/∃ 的顺序？ | 柯西-施瓦茨 vs 反向不等式（量词不可交换） |
| **隐含条件** | 能否识别"用对了就必须有"的条件？ | 交换极限与积分需要一致收敛，逐点不够 |

## 四、判据设计：混合判据

闭包只有 `Mathlib.Tactic`，不含分析/拓扑模块、不含 BigOperators ∑ 记号——纯 Lean 形式化覆盖面不够。采用**混合判据**：

### 主判据①：文本条件完整率

- 让模型自由列出定理的全部条件（自然语言）
- 按"关键条件清单"逐项打分：

  ```
  condition_completeness = |命中关键条件| / |关键条件总数|
  ```

- 关键条件清单由作者标注，**这就是为什么要老师复核**

### 主判据②：Lean 特例编译率

- 让模型写一个**该定理的特例 Lean 命题**：
  - E1：f(x) = x², [a,b] = [0,1] → ξ = 0.5（中值点）
  - E2：p = 11, a = 2 → 2^10 ≡ 1 (mod 11)
  - E3：n = 2 实数版：`|a₁b₁+a₂b₂| ≤ √(a₁²+a₂²) · √(b₁²+b₂²)`
- 编译通过 = 它**真懂**该定理在该特例下成立（隐含地用了所有必要条件）
- 这巧妙地把"陈述"映射回了 Lean 客观判据

### 指标体系

| 指标 | 定义 | 解读 |
|---|---|---|
| `condition_completeness_rate` | 关键条件被列出的平均比例 | < 0.7 = "会用但说不清" |
| `lean_special_ok_rate` | Lean 特例编译通过率 | 与上一行比对：**都高 = 真懂**；只高 Lean = 套模板 |
| `both_pass_rate` | 文本完整 **且** Lean 通过 | **论文 headline 指标** |

## 六、Lean 闭包约束下的逐题可行性

> **2026-09-05 已实测**，三道候选 gold 代码全部 PASS，比预期好。

| 题 | 可行性 | 最终方案 |
|---|---|---|
| E1 拉格朗日中值 | ✅ 可行（绕开 `deriv`） | **不必用 `deriv`**：直接把"ξ ∈ 开区间 (0,1)"编进命题，用 `Set.Ioo` + `use 1/2` + `norm_num`，避开导数定义 |
| E2 费马小定理 | ✅ 可行 | (p=11, a=2) 特例：2^10 % 11 = 1，`norm_num` 可验 |
| E3 柯西-施瓦茨 | ✅ 可行 | n=2 实数版：`nlinarith [sq_nonneg (a1*b2 - a2*b1)]` 一步证毕（Lagrange 恒等式） |
| E4 一致收敛 | ❌ 不可行 | 涉及极限，**降级为纯文本判据**，`gold_lean=""` |

**E1 的 gold（绕开导数的关键写法）**：

```lean
example : ∃ ξ : ℝ, ξ ∈ Set.Ioo (0:ℝ) 1 ∧
    2 * ξ = ((1:ℝ)^2 - (0:ℝ)^2) / (1 - 0) := by
  use 1 / 2
  constructor
  · norm_num
  · norm_num
```

> 这里的设计意图：命题里 `ξ ∈ Set.Ioo (0:ℝ) 1` 这一项**强制要求模型意识到
> "中值点必须落在开区间内部"**——这正是拉格朗日中值定理最常被含糊掉的条件。

## 七、与现有探针的关系

| 与 | 关系 |
|---|---|
| **C 反向构造** | 都测"造例子"，但 E 更精确（条件陈述级），C 是结构级（不限特定定理） |
| **D 一般→具体** | 都涉及条件，但 D 测"放宽条件后失效"（**判断层**），E 测"完整条件列出"（**陈述层**） |
| **B 陷阱** | 互补：B 测"识别被改坏的定理"（被动），E 测"主动正确陈述定理"（主动） |
| **层级** | E 是判断层之上的更严一层；**E 不替代 B/D，而是 B/D 的强化补充** |
