## 二、交付：prover → Lean 4.31 严格验证管线

**全部只新增，不回改 11-07/11-08 任何探针；不 import 项目包；不动 POLICY 101 项。**

| 文件 | 职责 |
|---|---|
| `prover_gate.py` | 纯函数契约：签名→官方 prompt→回复→服务器可编译代码 |
| `run_prover.py` | 调 OpenAI 兼容 endpoint，固定取 L2 B 组 18 题 `formal_sig`（同输入，满足 E14①） |
| `verify_proofs.py` | 批量送服务器编译，复用 E43 `compile_check_strict` 严格判据，分层统计 + 版本漂移候选 |
| `test_prover_gate.py` | 13 条单测 |
| `mock_selftest.py` | 5 条人工回复**真连服务器 Lean 4.31** 端到端自测 |
| `dryrun_sigs.py` | 零 LLM 预检：18 题套官方头后可陈述吗 |

### 三处必须适配（都来自实探，不是猜）

1. 官方 `import Mathlib` + `import Aesop` → `import Mathlib.Tactic`
   （服务器**没有顶层 `Mathlib.olean`**，MEMORY 已记）；
2. L2 的 `example ... := by sorry` → 官方要的 `theorem NAME ... := by sorry`
   （只改声明关键字，命题正文一字不动）；
3. 官方 `set_option maxHeartbeats 0`（不限心跳）→ `200000`，否则一条坏证明拖死整轮。

官方 prompt 逐字复刻（含 ```` ```lean4 {}``` ```` 围栏后**无换行**这个细节）：
要求先写详细 proof plan，再给完整 Lean 4 代码。

### 验证结果

| 检查 | 结果 |
|---|---|
| 契约层单测 | **13 passed** |
| 端到端 mock（真编译） | **5/5 PASS**：CLOSED / ERROR+漂移(`Unknown identifier`) / ERROR+sorry / UNSOLVED / NO_LEAN_BLOCK 逐条命中 |
| 18 题签名预检 | **18/18 STATABLE，ILLEGAL 0，硬错 0** |

`18/18` 的价值：证明 `example→theorem` + 官方头 + import 适配**没有引入任何环境错误**。
所以将来 prover 生成的证明一旦编译失败，就是 prover 自身或版本漂移，不能赖在适配上。

### 全量回归

`pytest tests tools -q`：**tests=2597 / failures=1 / errors=0 / skipped=7**，

## 四、现在只差一个 endpoint

管线已可运行，拿到推理地址后两步出数：

```
python run_prover.py --endpoint <ENDPOINT> --model <MODEL> --key <KEY> \
    --temperature 0 --out replies.json
python verify_proofs.py --replies replies.json --out results.json
```

`results.json` 会给：CLOSED / ERROR / UNSOLVED / 预检失败分层、
首错类型分布、以及 `drift_candidates`（unknown constant/identifier/
namespace/tactic 计数）——后者直接回答「Lean 4.9 → 4.31 漂移有多大」。

三条可选路径：

1. **托管 API**（Featherless 等，OpenAI 兼容）：最省，需一个 key；
   18 题 × 8K 输出上限粗估 ~$0.3 量级。当天可出数。
2. **本机 llama.cpp + `Q4_K_M` 5.03GB**：一次性下载约 2 小时 + 解决
   Windows CUDA 运行时获取；之后零调用费、可反复跑。
3. **改方向**：转命题级忠实度（量化恒假 / 空真两类）。

★ 真要接进智能体时：endpoint/model 目前是**探针参数**，不是 env/config 覆盖链；
按项目铁律，生产接线前必须先论证并登记策略项，不得做成开关。
