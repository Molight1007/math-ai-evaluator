## 4. A/B 实验结论

### 4.1 决策记录

| 能力 | 结论 | 依据 | 是否合入默认 |
|------|------|------|------------|
| `verifier_voting_times` | 保守（1 票） | voting=3 与 voting=1 同为 6/6，准确率无增量、耗时 +23%、调用预算翻倍 | 否 |
| `use_scoring` | 不合入 | scoring+proof 合并评测 6/6 但耗时 +163%（267.3s），性价比低 | 否 |
| `max_revise_rounds=1` | 合入 | 6/6 无损失，输出含推理结论更易读，耗时 +21% 可控 | 是 |
| `use_proof_channel` | 不合入 | 证明通道在本地集无准确率增益、耗时显著 ↑ | 否 |
| `use_blueprint` | 不合入 | 5/6 且耗时 269s（+165%）；唯一错题为答案提取边界（predicted 含正确选项但无"故选"标记），存在格式不稳定性 | 否 |
| `SubGoalSolverAgent` 接入 | 合入（保守开关） | 已接入；默认关闭（`use_sub_goal=False`），本地集触发分支未导致准确率损失 | 默认关，可开启 |

### 4.2 资源约束校验

| 约束 | 校验结果 |
|------|---------|
| 单题 LLM 调用 ≤ 15（最终默认预算） | 最终配置（revise=1, voting=1）达标；fast_path 命中可低至 1-2 次 |
| 单题耗时 < 1200s（平台硬限） | 实测最高 374.8s（full_open 选择题）；最终配置平均 123.4s，余量充足 |
| 总调用量在 6h/限流内 | 6 题 wall 323~414s；千题规模按并发 3、RPM 30 复核：单题 ≤15 次调用 + 300s 内可容纳 |
