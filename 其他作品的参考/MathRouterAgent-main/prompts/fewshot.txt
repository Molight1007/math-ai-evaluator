Question: A parabola with equation $y=x^2+bx+c$ passes through the points $(-1,-11)$ and $(3,17)$. What is $c$?

<tool_call>
import sympy as sp
x, y, b, c = sp.symbols('x y b c')
eq = sp.Eq(y, x**2 + b*x + c)
solutions = sp.solve((eq.subs({x:-1, y:-11}), eq.subs({x:3, y:17})), (b, c))
print(solutions[c])
</tool_call>
```output
-7
```
\boxed{-7}

Question: At the 2007 Math Olympics, Team Canada won $17$ out of a possible $100$ medals. Which is closest to the fraction of medals they won? $$\frac{1}{4} \qquad \frac{1}{5} \qquad \frac{1}{6} \qquad \frac{1}{7} \qquad \frac{1}{8}$$

<tool_call>
from sympy import Rational, Abs
medal_frac = Rational(17, 100)
options = [Rational(1, n) for n in range(4, 9)]
diffs = [Abs(medal_frac - opt) for opt in options]
print(options[diffs.index(min(diffs))])
</tool_call>
```output
1/6
```
\boxed{\dfrac{1}{6}}

Question: A rectangular box $P$ is inscribed in a sphere of radius $r$. The surface area of $P$ is 384, and the sum of the lengths of its 12 edges is 112. What is $r$?

<tool_call>
from sympy import symbols, Eq, solve
x, y, z, r = symbols('x y z r')
eq1 = Eq(2*(x*y + x*z + y*z), 384)
eq2 = Eq(4*(x + y + z), 112)
eq3 = Eq(x**2 + y**2 + z**2, (2*r)**2)
solutions = solve((eq1, eq2, eq3), (x, y, z, r))
print([s[-1] for s in solutions])
</tool_call>
```output
[-10, -10, 10, 10]
```
\boxed{10}

Question: Does there exist a monic cubic polynomial $P(x) = x^3 + ax^2 + bx + c$ with $a, b, c$ positive reals, such that $P$ has exactly one real root?

<tool_call>
from sympy import symbols, discriminant, Poly
x, a, b, c = symbols('x a b c')
P = Poly(x**3 + a*x**2 + b*x + c, x)
disc = discriminant(P, x)
print(disc)
</tool_call>
```output
-4*a**3*c + a**2*b**2 + 18*a*b*c - 4*b**3 - 27*c**2
```
<tool_call>
print(disc.subs({a:1, b:1, c:1}))
</tool_call>
```output
-16
```
\boxed{\text{Yes}}
