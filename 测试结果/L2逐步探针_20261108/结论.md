# E41：EMPTY 归因订正 + EMPTY 驳回实验 + 噪声底（2026-11-08）

三件事，按证据强度排序：

1. **订正**：L2 失败分布里的 `EMPTY` 不是「模型不会下手」，是**模型谎报完成**。
2. **实验**：EMPTY 改成「驳回并让它续写」后，驳回 **16 轮 / 16 轮全部写出非空 tactic（100%）**，
   但**闭合率不变**（2/18）。
3. **★ 顺带量出的噪声底**：同一份代码、同一台机、同一天、`temperature=0` 重跑，
   **18 题第一步只有 8 条相同**，`pass` 从 2/18 掉到 1/18 ⇒ **n=18 的两臂对比没有鉴别力**。

## 1. 订正：EMPTY = 谎报完成

`L2逐步探针_20261107/` 四路共 **21 条 EMPTY**，逐条查 trace：

| 检查项 | 结果 |
|---|---|
| EMPTY 那步的理由 | **20/21 条**写「目标已被前面的 XXX 闭合」（仅 1 条无理由） |
| 同一步上一步的编译状态 | **全部 `UNSOLVED`** |
| 同一时刻 trace 里的 goal | **全部非空**（如 `⊢ False`、`⊢ ∀ i, x i ^ 2 ≤ 777 ^ 2`） |
| 发生时机 | 全部在第 3~10 步（**不是第 1 步**） |

原文举例（`b_fix/q01` 第 5 步）：

```
目标：x y z : ℝ … ⊢ False
TACTIC:（空）
REASON: 目标 False 已被 exact h3 闭合，无需进一步步骤。
上一步 exact h3 的编译结果：UNSOLVED
```

⇒ 旧记录「EMPTY 8（44%，不会下手）」**归因错误**，应改为「**模型自报证完了，而编译器说没完**」。
`MEMORY.md` 已订正。

这一条不依赖跑数，是 trace 内部一致性证据。

## 2. 单变量实验：EMPTY 驳回续写

改动只有一处（`l2_empty_reject.py` vs `l2_step_probe.py`）：

> `if not tactic:` 分支不再直接终止，而是把「编译器刚编译过前缀，仍报 unsolved goals + 目标原文」
> 当证据回给模型，让它续写；不消耗步骤数，最多 2 轮（`--empty-rejects`）。
> 提示词 / Lean4 语法表 / 编译错误反馈轮数 / 检索通道 **一律不动**。

### 结果

| 指标 | 结果 |
|---|---|
| 驳回总轮次 | 16 |
| 驳回后写出非空 tactic | **16（100%）** |
| 基线 8 条 EMPTY 的去向 | MAX_STEPS 4（q03/q05/q08/q11）、BANNED 2（q01/q09）、COMPILE_ERROR 1（q20）、EMPTY_CONFIRMED 1（q25） |
| 闭合率 | 2/18（与基线相同） |

驳回原文样本：

| tag | 模型声称 | 被驳回后写的 |
|---|---|---|
| q05 | 目标已被前面的证明步骤闭合 | `rw [hk]` |
| q08 | 目标已被前面的 `exact h777` 闭合 | `intro i` |
| q25 | 证明已通过 linarith 闭合 | `linarith [h01, h1_sq_le']` |

⇒ **「空」不是「不会」**：一被指出矛盾就 100% 能接着写。
⇒ 但**接着写 ≠ 能证完**：6 条从 EMPTY 转成 MAX_STEPS 或 BANNED，说明它是在打转，不是差一步。

## 3. ★ 噪声底：n=18 的对比没有鉴别力

| 臂 | 日期 | pass | 步1 与本臂对照 |
|---|---|---|---|
| `b_fix` 旧协议 | 11-07 | 2/18 | — |
| `base2` **同一份代码重跑** | 11-08 | **1/18** | 与 `b_fix` 步1 一致 **8/18** |
| `rej` 驳回续写 | 11-08 | 2/18 | 与 `base2` 步1 一致 12/18 |

`temperature=0`、同机、同日、同代码，18 题里 **10 题第一步就写了不同的 tactic**（例：q02 `ring` vs 一长串 `have`；
q24 两种不同的 `by_cases`；q10 `by norm_num` vs `by omega`）。

**这条的意义比协议修正大**：

- `pass` 在 1~2/18 之间抖 ⇒ 过去「五路收敛 1-2/18」的准确表述是
  **五路全在噪声底内、彼此不可分辨**，而不是「五路各自收敛到同一处」。
- 机制层面解释了 E14 为什么要求 n≈377：不只是统计功效，**底层生成本身就不确定**。
- ⇒ **任何 n=18 的两臂 A/B 都不能当效果量**，包括本轮的 2 vs 2。

## 4. 不宣称

- 不宣称「驳回续写提升了闭合率」（2 vs 2，且在 1~2 的噪声带内）。
- 不宣称 `rej` 与 `base2` 的 stop 分布差异来自协议（步1 就分叉了，路径不可比）。
- 「EMPTY 100% 可驳回」只说明**这一句谎话可以当场戳破**，不说明模型因此接近正确。
