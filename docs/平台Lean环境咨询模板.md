**1. Lean 工具链是否预装？**
线上评测环境是否预装 Lean 4 及 elan/lake 工具链？若预装，具体版本是什么（我们本地为 v4.31.0，olean 产物与版本严格绑定）？Lean 可执行文件在环境中的路径是什么？

**2. 依赖安装机制具体是什么？**
规则提到"隔离环境自动安装项目依赖"——具体执行哪些命令？是否仅执行 `pip install -r requirements.txt`？能否支持在安装阶段运行自定义脚本（如 shell 命令）？如果提交包内附带可执行文件（如精简版 lean 二进制），是否会被安全策略拦截？

**3. 提交包大小限制是多少？**
提交仓库/打包的体积上限是多少？（若允许，我们可只附带证明所需的精简 Lean 工具链，而非完整 3-5GB 的 mathlib）

**4. 运行环境资源参数？**
我们已确认评测环境**无外网**（无法 lake 拉取/构建依赖）。请确认：操作系统（Linux/Windows）、CPU/内存上限、单题运行超时时间。
（若环境无外网且未预装完整 mathlib，则 Lean 验证在平台不可行——我们可接受，仅需明确资源参数以便本地对齐模拟。）

**5. 提交包内附带的库文件是否合规？**
官方规则提到"禁止读取本地私有文件/绝对路径"——如果我们将必要的库文件（如 .olean）作为**提交包内相对路径**的一部分使用，是否合规？

**6. 官方 Client 的模型是什么？**
平台官方 Client 托管的是书生系列哪个具体模型（Intern-S1 / Intern-S2-Preview-397B / 其他）？模型版本是否与本地开发一致？
