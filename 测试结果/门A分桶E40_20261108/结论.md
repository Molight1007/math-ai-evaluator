# 门A 只读分桶 `goal_is_false`（E40，2026-11-08）

把「反证骨架」从 STATABLE 里分出来的**纯度量改动**。不改判据、不改 `allowed`、
不动 POLICY 101 项、不新增开关。

## 1. 为什么做

`测试结果/门A退化命题探针_20261108/` 量出：87 条 STATABLE 里有 **8 条（9.2%）**的命题
字面就是 `False`：

```lean
example (x : ℝ) (hx : x ≠ 0) (h1 : 3*x^2 = 3) (h2 : 3*x^4 = 3) : False := by sorry
```

这类签名语法永远合法 ⇒ 门A 必然判 STATABLE；但它可不可证完全取决于**假设是否
自相矛盾**——那是门A 判据之外的东西（要判它等于要求给出真证明）。
上例 `x = 1` 满足全部三个假设 ⇒ `False` 不可证，门A 照样给 STATABLE。

不修判据（修不了），只加**只读分桶**，避免「STATABLE 60.4%」日后被当忠实度引用。
