# 形式签名命题保真度 · 人工抽验清单

> 生成：2026-11-06｜抽样框 160 条去重签名 / 23 题｜本单 26 条 / 16 题｜固定种子 20261106

**为什么做**：门A 只判「命题能不能编译」，不判「是不是原题的意思」。Goedel-Prover-V2 在 Omni-MATH 上报告未解问题里 >80% 是形式化写错；项目内 E29 也发现编译通过挡不住语义空洞。本单用于把「命题写歪/空洞」与「证不出」分开。

**盲审纪律**：本单不含任何系统判定（编译结论、工具结论、对错、运行轮次）。答案表单独存放，抽验完成后方可对照。

## 判定标准

| 档 | 含义 |
|---|---|
| **A** | 忠实 — 签名准确表达该子目标，量词/类型/常数/定义域与原题一致 |
| **B** | 命题写歪 — 改了题意：量词方向、变量域、常数、把待证结论写成假设、求解题改证明/反证、拆成分类证明 |
| **C** | 空洞/平凡 — 恒真或前提矛盾：True、A=A、假设直接蕴含结论、ℕ 减法/除法造成的假等式 |
| **D** | 信息不足 — 题目或签名残缺，无法判定 |

**规则**

- := by sorry 是分工设计（E30），不因出现 sorry 判 B/C
- 只判「这条签名是否忠于这个子目标 + 原题」，不判能不能证出来
- B/C 必须在备注里写出具体错在哪一处
- 未抽验完毕不得下结论；不作统计推断、不作效果量
